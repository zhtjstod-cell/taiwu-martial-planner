태오회권 무공 추출기 1.2 · Windows 포터블
==================================

1. ZIP을 완전히 압축 해제합니다.
2. `태오회권_무공추출기.bat`을 실행합니다.
3. Steam 설치 위치를 찾지 못하면 게임 폴더를 BAT 파일 위에 끌어놓습니다.
4. `output\태오회권_무공데이터.json`을 사이트의 `데이터 업로드` 버튼으로 불러옵니다.

BAT 파일은 코드페이지 영향을 받지 않는 ASCII 실행용 파일입니다. 한글 안내와 실제 추출 절차는
UTF-8 BOM으로 저장된 `run-extractor.ps1`이 담당하고, Steam 경로 탐색은
`find-taiwu-game.ps1`로 분리되어 있습니다.

필수 프로그램
-------------
- 64비트 Windows 10/11

Node.js, Python, UnityPy, .NET 8 런타임과 ILSpy가 ZIP의 `.runtime`에 포함되어 있습니다.
별도 설치, 인터넷 연결, 관리자 권한이 필요하지 않습니다. `.runtime`을 삭제하거나 ZIP 안에서
직접 실행하지 말고 전체 폴더를 먼저 압축 해제하세요.

개인정보 및 배포 범위
--------------------
- 결과에는 Steam 계정, 세이브, 로그, 전체 설치 경로가 포함되지 않습니다.
- 게임 전체 에셋이 아니라 운공 화면에 필요한 공법 아이콘만 결과 JSON에 포함됩니다.
- 업로드한 데이터는 해당 브라우저의 IndexedDB에만 저장되며 공용 기본 데이터를 덮어쓰지 않습니다.
- GitHub에 결과 JSON을 올릴 때는 포함된 게임 아이콘의 재배포 권리를 먼저 확인하세요.
