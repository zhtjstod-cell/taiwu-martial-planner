태오회권 무공 추출기 1.0
========================

1. 압축을 푼 뒤 `태오회권_무공추출기.bat`을 실행합니다.
2. Steam 설치 위치를 자동으로 찾지 못하면 게임 폴더를 BAT 파일 위에 끌어놓습니다.
3. `output\태오회권_무공데이터.json`이 생성되면 무공 플래너의 `데이터 업로드` 버튼으로 불러옵니다.

필수 프로그램
-------------
- Windows 10/11
- Node.js 22 이상
- Python 3.11 이상
- .NET 8 SDK

처음 실행할 때 전용 `.runtime` 폴더에 UnityPy와 ILSpy를 설치합니다. 게임 파일은 읽기만 하며 수정하지 않습니다.

개인정보 및 배포 범위
--------------------
- 결과에는 Steam 계정, 세이브, 로그, 전체 설치 경로가 포함되지 않습니다.
- 게임 전체 에셋이 아니라 운공 화면에 필요한 공법 아이콘만 결과 JSON에 포함됩니다.
- 업로드한 데이터는 해당 브라우저의 IndexedDB에만 저장되며 공용 사이트 기본 데이터를 덮어쓰지 않습니다.
- GitHub에 올릴 때는 결과 JSON에 포함된 게임 아이콘의 재배포 권리를 먼저 확인하세요.
