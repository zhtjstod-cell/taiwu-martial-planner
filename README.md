# 태오회권 무공진

태오회권의 실제 게임 데이터와 전투 코드를 읽어 정·역련별 시너지와 카운터를 설명하는 운공 플래너입니다.

## 데이터 추출

게임 설치 폴더는 읽기만 합니다. 추출기는 다음 세 자료를 합칩니다.

- `GameData.Shared.dll`: 무공의 품계, 계통, 점유 칸, 정·역련 특효 ID와 5계통 장착칸 규칙
- `SpecialEffect_language.txt`: 한국어·중국어 특효 설명과 짧은 효과명
- `GameData.dll`: 무공별 실제 이벤트, 판정, 오래된 부상 제외처럼 툴팁에 생략된 조건과 공통 기반 클래스
- `Assembly-CSharp.dll`: 정식 출시 운공 UI의 카드 비율, 만능칸 재분배와 복수 운공안 지원 구조
- `Language_KO`: 공법·문파·유형·무기·식의 한국어 정식 명칭
- `GameResources/*.uab`: 운공 원판, 계통 문양, 칸·공법 카드와 문파/오행 아이콘

```powershell
npm install
npm run extract -- --game "D:\SteamLibrary\steamapps\common\The Scroll Of Taiwu" --portable ".\태오회권_무공데이터.json"
npm run extract:ui
npm run dev
```

일반 사용자는 GitHub Releases에서 운영체제에 맞는 추출기를 받습니다. Windows판은 ZIP을 풀고 `태오회권_무공추출기.bat`을 실행합니다. BAT는 코드페이지에 영향을 받지 않는 ASCII 부트스트랩이며 한글 안내·의존성 검사·실행은 UTF-8 BOM PowerShell 파일, Steam 경로 탐색은 별도 PowerShell 파일이 담당합니다. Linux판은 TAR.GZ를 풀고 `bash taiwu-martial-extractor.sh`를 실행합니다. 네이티브 Steam과 Flatpak Steam의 `libraryfolders.vdf`를 읽어 Proton이 사용하는 게임 설치 폴더를 찾으므로 Wine에서 BAT를 실행할 필요가 없습니다.

두 추출기 모두 생성된 `output/태오회권_무공데이터.json`에 사이트에서 필요한 실제 인게임 공법 아이콘을 포함합니다. 사이트 상단 `데이터 업로드`에서 파일을 고르면 스키마·중복 ID·운공칸을 검증한 뒤 해당 브라우저에 즉시 적용하고 IndexedDB에 보존합니다. 임의 사용자가 공용 기본 데이터를 바꾸지는 못합니다.

추출 버전은 게임 버전, Steam 빌드 ID, 한국어 로컬라이징 모드와 그 버전을 함께 기록합니다. 기본 `Language_KO`를 읽은 뒤 설치된 한국어 로컬라이징 모드를 덮어써 실제 플레이 화면의 명칭을 우선합니다.

ILSpy CLI는 `--ilspy` 또는 `ILSPYCMD`로 지정할 수 있습니다. 배포 추출기는 전용 `.runtime`에 설치합니다. `.NET Runtime`만으로는 설치할 수 없으므로 Windows와 Linux 실행기 모두 `dotnet --list-sdks`에서 8.0 이상의 SDK를 확인하고 구체적인 설치 오류를 표시합니다.

## 업데이트 대응 방식

추출기는 고정된 무공 ID 목록이나 무공별 예외 목록을 갖지 않습니다. 새 DLL을 다시 역컴파일해 생성자 호출과 상속 계층을 읽고, 모든 정·역련 코드를 `발동 이벤트 → 조건 → 대상 → 동작 → 자원 → 수치` 중간표현으로 변환합니다. 알려진 전투 개념은 한국어 이름으로 세분화하며, 목록에 없던 신규 개념도 인용 용어, 특효 축, 열거형 상태, 코드 이벤트, 전투 메서드와 변경 필드로 보존합니다.

각 정·역련에는 아래 관계 자료가 생성됩니다. 공법칸은 클라이언트와 서버 공식을 함께 읽어 기본 `6·1·1·1·1`칸, 내공의 전용칸·만능칸 제공, 계통별 최대 9칸, 정해 시 점유 1칸 감소와 내공 제공칸 전환을 계산합니다.

- 발동 시점
- 생산·소모·제거·증폭·감소·금지 자원
- 요구 조건
- 동적으로 발견한 특효 축
- 실제 코드 이벤트와 전투 메서드
- 직접 클래스와 공통 기반 클래스의 조건·대상·변경 동작
- 무기군·식 조합·최소/최대 사거리와 사거리 증감
- 준비 진행, 신법·자세·호흡 소모, 내외상 비율과 파체·파기
- 명중 분포, 공격 부위, 점혈·파열, 고독, 반격·반진, 장비 파손

시너지는 한 공법이 `자신`에게 만든 이로운 자원 또는 `적`에게 만든 해로운 상태가 다른 공법의 같은 대상 조건·소모·증폭으로 이어질 때만 생성합니다. 카운터는 공격 상태를 `자신`에게서 방어하거나, 상대의 이로운 강화·필수 자원을 `적`에게서 제거하는 역관계와 오래된 부상·무기 사거리 같은 별도 전투 규칙만 사용합니다. 적의 부상·패배 표식을 제거하는 효과처럼 상대를 돕는 동작은 전수 감사에서 카운터 후보로 차단합니다.

봉금은 별도 관계 축으로 분석합니다. 추출기가 금강·자하·현음·순양·귀원·혼원 중 효과가 실제로 지정한 계통만 판별해 해당 공법의 카운터로 연결하고, 봉금 저항·즉시 해제는 방어 카운터로, 봉금 시간 연장·봉금 해제 시 추가 발동은 시너지로 연결합니다. 코드의 `SilenceSkill`과 `ClearSkillCd`를 실제 봉금 변경으로 읽으며 `DisableJumpMove` 같은 다른 행동 금지는 봉금으로 오인하지 않습니다.

사이트 검색은 공법명뿐 아니라 정·역련 전체 설명, 짧은 효과명, 태그, 발동 조건, 대상·자원과 코드 근거를 함께 검색합니다. 공법 목록은 1~9품 필터와 고품(1품)·저품 정렬을 제공합니다.

## GitHub 자동 갱신

`.github/workflows/extract-game-data.yml`은 게임이 설치된 self-hosted Windows runner에서 수동 또는 매일 실행합니다. 새 데이터나 운공 UI 에셋에 변화가 있을 때만 추출 결과를 커밋합니다. 게임 전체 파일은 저장소에 올리지 않습니다.

## 공략 게시판과 개인정보

공략은 자유 서술 없이 제목과 현재 운공 조합, 추출 데이터 버전만 저장합니다. 별도의 관계 제보 게시판은 기준·관련 공법, 정·역련, 시너지/카운터 유형과 10~500자의 근거만 받으며 링크와 제어 문자를 차단합니다. 추천과 제보 중복·속도 제한에는 Cloudflare가 전달한 IP를 서버 비밀키로 HMAC-SHA-256 처리한 값만 사용하고 IP 원문은 저장하지 않습니다. 게시판은 Cloudflare Pages Functions와 D1을 사용하므로 개발자가 별도 서버를 계속 실행할 필요가 없습니다.

## Cloudflare Pages 배포

공개 사이트는 [taiwu-mugongjin.pages.dev](https://taiwu-mugongjin.pages.dev)에서 동작합니다. `npm run build:pages`는 vinext 클라이언트 빌드에서 정적 HTML을 만들고, `/api/strategies`만 처리하는 작은 Pages Worker를 `.pages-deploy`에 생성합니다. `wrangler.jsonc`의 `DB` 바인딩은 전용 D1을 가리키며 `VOTE_HMAC_SECRET` 값은 Cloudflare의 암호화된 환경 변수에만 저장합니다.

```powershell
npm run cf:types
npm run build:pages
```

Pages 프로젝트의 프로덕션 브랜치는 `main`, 호환성 날짜는 `2026-08-01`, 플래그는 `nodejs_compat`입니다. 배포 전 `drizzle/0000_dry_lethal_legion.sql`을 D1에 적용해야 합니다.

새 관계 제보 테이블을 추가하는 배포에서는 `drizzle/0001_worried_lorna_dane.sql`도 순서대로 적용합니다.
