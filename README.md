# 태오회권 무공진

태오회권의 실제 게임 데이터와 전투 코드를 읽어 정·역련별 시너지와 카운터를 설명하는 운공 플래너입니다.

## 데이터 추출

게임 설치 폴더는 읽기만 합니다. 추출기는 다음 세 자료를 합칩니다.

- `GameData.Shared.dll`: 무공의 품계, 계통, 점유 칸, 정·역련 특효 ID와 5계통 장착칸 규칙
- `SpecialEffect_language.txt`: 한국어·중국어 특효 설명과 짧은 효과명
- `GameData.dll`: 무공별 실제 이벤트, 판정, 오래된 부상 제외처럼 툴팁에 생략된 조건과 공통 기반 클래스
- `Assembly-CSharp.dll`: 정식 출시 운공 UI의 카드 비율, 공용칸 재분배와 복수 운공안 지원 구조

```powershell
npm install
npm run extract -- --game "H:\SteamLibrary\steamapps\common\The Scroll Of Taiwu"
npm run dev
```

ILSpy CLI는 `--ilspy` 또는 `ILSPYCMD`로 지정할 수 있습니다. 로컬에 없으면 `dotnet tool run ilspycmd`를 사용합니다.

## 업데이트 대응 방식

추출기는 고정된 무공 ID 목록이나 무공별 예외 목록을 갖지 않습니다. 새 DLL을 다시 역컴파일해 생성자 호출과 상속 계층을 읽고, 모든 정·역련 코드를 `발동 이벤트 → 조건 → 대상 → 동작 → 자원 → 수치` 중간표현으로 변환합니다. 알려진 전투 개념은 한국어 이름으로 세분화하며, 목록에 없던 신규 개념도 인용 용어, 특효 축, 열거형 상태, 코드 이벤트, 전투 메서드와 변경 필드로 보존합니다.

각 정·역련에는 아래 관계 자료가 생성됩니다.

- 발동 시점
- 생산·소모·제거·증폭·감소·금지 자원
- 요구 조건
- 동적으로 발견한 특효 축
- 실제 코드 이벤트와 전투 메서드
- 직접 클래스와 공통 기반 클래스의 조건·대상·변경 동작
- 무기군·식 조합·최소/최대 사거리와 사거리 증감
- 준비 진행, 신법·자세·호흡 소모, 내외상 비율과 파체·파기
- 명중 분포, 공격 부위, 점혈·파열, 고독, 반격·반진, 장비 파손

시너지는 한 무공의 코드 동작이 만든 자원이 다른 무공의 조건·소모·증폭 대상으로 이어질 때 우선합니다. 카운터는 상대의 생산물이나 요구 조건을 제거·감소·금지하거나 무기·식·사거리 조건을 무너뜨리는 관계를 우선합니다. 같은 단어만 있다는 이유로 낮은 근거의 추천을 만들지 않습니다.

## GitHub 자동 갱신

`.github/workflows/extract-game-data.yml`은 게임이 설치된 self-hosted Windows runner에서 수동 실행합니다. 새 데이터에 변화가 있을 때만 `app/data/combat-skills.json`을 커밋합니다. Steam 게임 파일은 저장소에 올리지 않습니다.
